# Instructor run of show · Chapter 1 (3 hours)

PIAIC Advance Agentic AI, Karachi. Project [`index.html`](https://qasim-077.github.io/PIAIC-Advance-agenticAI-Karachi/) and press **▶** on the session clock when class starts. The clock is shared across pages, and the agenda highlights the current block.

## Before class

- [ ] Open the site on the projector laptop. Test dark or light mode for the room.
- [ ] Sign in to Claude **and** ChatGPT, so you can demo either.
- [ ] Download and unzip [`brightline-lab-ch01.zip`](https://github.com/panaversity/agentfactory-v2-resources/releases/latest/download/brightline-lab-ch01.zip) yourself, and run Task 1 once, so you know how long it takes on your plan.
- [ ] Share the site link with students: `https://qasim-077.github.io/PIAIC-Advance-agenticAI-Karachi/`
- [ ] Ask students to download the kit before class. Venue Wi-Fi is the most common delay.

## Part 1 · Theory (0:00 – 1:30), [theory.html](https://qasim-077.github.io/PIAIC-Advance-agenticAI-Karachi/theory.html)

| Clock | Block | Do on screen | Ask the class |
| --- | --- | --- | --- |
| 0:00 – 0:10 | **Maria's week** | Click Monday → Wednesday → next Monday | "What would you have asked on Monday instead?" "Where did the spreadsheet go?" |
| 0:10 – 0:25 | **1.1 Ladder** | Animate the climb. Let the AI Worker traits light up. Play the sorting game as a class. | "Is a weekly register a task or a role?" "Why does each rung need more control?" |
| 0:25 – 0:38 | **1.2 Text box** | Start with no chips (Answer). Add Outcome alone (Work). Add the rest. Flip the 2023/2026 table. | "Who decides whether the box answers or works?" |
| 0:38 – 0:48 | **1.3 Where it runs** | Run the task loop. Toggle the boundary. | "If the code is sandboxed, can the agent still email someone through a connected app?" |
| 0:48 – 1:05 | **1.4 C · E · P** | The three toggles: flip one at a time. Play the three-places game. Toggle the desktop bridge. | "I flipped only Continuity. Which answers changed?" (Only its own.) |
| 1:05 – 1:15 | **1.5 Today's tools** | 2 minutes per vendor tab. Play machine-or-record in all three modes. | "For each tab: where does it run? Where is it kept?" |
| 1:15 – 1:23 | **1.6 Paradigm** | Paradigm-or-product game. Analyse one announcement with the four questions. | "Which of the four questions tells you what survives?" |
| 1:23 – 1:30 | **Quiz + exit ticket** | Run the 12 questions as a show of hands. | Exit ticket: "Remembering is not keeping." Explain it in your own words. |

**Pacing tip.** 1.4 is the heart of the chapter, and Lab Tasks 2, 5, 8, 9 and 10 all test it. If you are running late, shorten 1.5 (assign the vendor tabs as reading), not 1.4.

**Break.** 5–10 minutes, if the room needs it. Students open their AI account and unzip the kit during the break.

## Part 2 · Lab 1 (1:30 – 3:00), [lab.html](https://qasim-077.github.io/PIAIC-Advance-agenticAI-Karachi/lab.html)

| Clock | Step | Watch for |
| --- | --- | --- |
| 1:30 – 1:35 | **Setup and the job** | Students uploading `LAB.md` or `README.md` to the AI. They must not: those files link every answer key. |
| 1:35 – 1:45 | **The brief and the check loop** | Model one brief live, using the teacher's example. Show the check prompt. |
| 1:45 – 2:00 | **Task 1 · What we owe** | Briefs missing the facts under Context: today's date, and that 4471 was paid on September 25. |
| 2:00 – 2:20 | **Task 2 · A spreadsheet for Friday** | The "files you did not deliver" question. Spreadsheets opened in a tool that shows formulas as blanks. Ask: "Where is your spreadsheet right now?" |
| 2:20 – 2:28 | **Task 3 · What is due by Friday** | Students re-attaching files. The AI already has them (1.3: files persist while the environment lasts). |
| 2:28 – 2:36 | **Task 4 · Match the POs** | Briefs that ask only yes/no. The manager wants the reason for each mismatch. |
| 2:36 – 2:44 | **Task 5 · A doc for the controller** | Can each student find the doc again? Claude: the Artifacts section. ChatGPT: in the conversation. |
| 2:44 – 2:52 | **Task 6 · Which surface for which job** | The AI answering for the student. The printed brief says "Ask only". Students decide; don't give the answers away before the key. |
| 2:52 – 2:58 | **Task 9 · Where each result lives** | Skip result 4 (Task 8 is homework). Link back to the three places in 1.4. |
| 2:58 – 3:00 | **Wrap-up and homework** | Assign the homework below. |

**If the class falls behind:** do Tasks 1, 2, 5 and 9 in class, and move Tasks 3, 4 and 6 to homework. Tasks 2 and 9 carry the chapter's main idea.

**Grading in class.** Each task ends with the check prompt and its answer key. Ask students to post their pass count (for example, "Task 1: 3/3") in the class chat after each task, so you can see who is stuck.

## Homework

- **Task 7.** Run the same briefs on the other vendor (Claude ↔ ChatGPT), and note every change.
- **Task 8.** Save the Friday spreadsheet into a `Brightline AP` folder, through a desktop app.
- **Task 10.** At least one day later: what survived?
- **Part B (optional).** Tasks 11–14: close the laptop, a Monday schedule, version history, and the AI inside a spreadsheet. Some need paid plans or a Google account.
- **Apply it to your vertical.** Use real files from your own line of work. Write one brief, and place five jobs on the ladder.
